# 野人理論原典ガイド

野人さんが公開している野人理論を、作成者自身が原典を確認しながら理解する過程で作成している個人的な学習・整理資料です。

このリポジトリーは、野人さん本人による公式サイトや公式解説ではなく、公式な体系を示すものでもありません。

野人理論をこちら側で完成させたり再定義したりすることではなく、読者が野人さん自身の原典へたどり着き、自分で確認できる入口を作ることを目的としています。

## このリポジトリーの基本方針

野人理論の内容を判断する際の最上位の根拠は、野人さん自身の原典です。

このリポジトリーでは次の原則を守ります。

- 野人さんが述べている内容と、作成者による整理を区別する
- 野人さんが述べていない内容を補完したり再定義したりしない
- 原典の出典を可能な限り追跡できる形にする
- 確認できていないことを推測で埋めない
- 「確認できない」と「述べていない」を区別する
- 原典間に違いや未解決の関係がある場合は、無理に一つの体系へまとめない
- 原典確認の進展に合わせて継続的に更新する

## 原典関係マップについて

今後、このリポジトリーでは原典同士の関係を確認しやすくするための原典関係マップを公開します。

原典関係マップは、原典研究で確認した内容を整理するための参照資料です。

原典そのものではなく、野人さん本人が提示した公式な体系図でもありません。

最終的な確認は、リンク先の原典そのものを参照してください。

## 公開予定の資料

原典研究で確認済みの成果から順次、次の資料を追加します。

- 原典一覧
- 原典ごとの確認情報
- 原典関係マップ
- reading-guide（原典を読むための案内）
- テーマ別の原典導線
- 調査・整理方法
- 更新履歴

公開前の調査メモ、未検証の推測、非公開情報などは公開資料とは分離して扱います。

## 資料の区分

公開資料では必要に応じて、次の内容を区別します。

1. 原典で確認できる内容
2. 作成者による整理
3. 必要な場合に限る作成者による考察

作成者による整理や考察を、野人さん本人の主張として扱いません。

作成者による考察を掲載する場合は、原典で確認できる内容や作成者による整理とは明確に分離します。

## 訂正と更新

このリポジトリーは完成版ではありません。

新しい原典の確認、既存原典の再確認、誤りの発見などに応じて内容を更新します。

重要な変更については変更履歴に記録します。

## 著作権と引用

野人さんの原典の著作権は、それぞれの権利者に帰属します。

このリポジトリーでは原典全文の転載を目的とせず、必要最小限の引用と要約を用いながら原典へのリンクを示します。

詳細は `RIGHTS.md` を参照してください。

## 観生｜生命を考える

このリポジトリーは公開活動「観生｜生命を考える」の一部です。

「観生｜生命を考える」は観生プロジェクトの対外的なブランド表現であり、野人理論そのものの名称ではありません。

理人理論（仮称）は野人理論とは別の理論として扱い、このリポジトリーにはその理論内容を混在させません。

## この活動の目的

野人理論を広めることより先に、野人さんが何を述べたのかを出典を追える形で正確に伝えることを優先します。

原典を転載・代替するのではなく、原典へ導くこと。

野人理論を完成させるのではなく、理解を助けること。

野人さんを代弁するのではなく、読者が自分で原典を読めるようにすること。

そのための入口として、このリポジトリーを整備していきます。
