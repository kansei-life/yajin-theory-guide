# 野人理論原典ガイド

公開版：Version 0.1

野人さんが公開している野人理論を、原典までたどって確認できるように整理した非公式ガイドです。

このリポジトリーは、野人さん本人による公式サイトや公式解説ではなく、野人理論の公式な体系を示すものでもありません。

目的は、野人理論をこちら側で完成させたり再定義したりすることではなく、読者が野人さん自身の原典へたどり着き、自分で確認できる入口を作ることです。

## Version 0.1について

Version 0.1は、確認済みの研究成果を原典まで追跡できる形でまとまって提示する最初の正式公開版です。完成版を意味しません。

Version 0.1では、S001〜S074の74件を公開対象としています。74件すべてについてページ確認と本文到達確認を行っていますが、原典網羅性は継続調査中です。

公開日時・公開年には確認継続中の項目があります。個別原典レコードでは確定情報と参考情報を区別し、推測で補いません。

## このリポジトリーの基本方針

野人理論の内容を判断する際の最上位の根拠は、野人さん自身の原典です。

このリポジトリーでは次の原則を守ります。

- 野人さんが述べている内容と、作成者による整理を区別する
- 野人さんが述べていない内容を補完したり再定義したりしない
- 原典の出典を可能な限り追跡できる形にする
- 確認できていないことを推測で埋めない
- 「確認できない」と「述べていない」を区別する
- 原典間に違いや未解決の関係がある場合は、無理に一つの体系へまとめない
- 原典確認の進展に合わせて継続的に更新する

## 資料の区分

公開資料では必要に応じて、次の内容を区別します。

1. 原典で確認できる内容
2. 作成者による整理
3. 必要な場合に限る作成者による考察

作成者による整理や考察を、野人さん本人の主張として扱いません。

「原典内直接記述」「複数原典横断整理」「学習上の整理」や、「確認済み」「部分確認」「未確認」などの表示がある場合は、その区分を維持して読んでください。

## 原典関係マップについて

原典関係マップは、原典研究で確認した内容を整理するための参照資料です。

原典そのものではなく、野人さん本人が提示した公式な体系図でもありません。

最終的な確認は、各資料からリンクしている原典そのものを参照してください。

## 未確認事項について

Version 0.1では、確認できていない関係を隠さず、[未確認事項](docs/open-items.md)として確定情報と分離して公開します。

未確認事項は誤りと断定したものでも、こちら側で補完してよい事項でもありません。追加原典の確認などによって研究を継続する対象です。

未確認IDは履歴追跡のため固定しています。番号に欠番が見える場合や、別系列で同じ番号が使われる場合は[未確認事項の履歴](docs/unresolved-history.md)で状態を確認できます。

## 健康・生活に関する記述について

このリポジトリーには、健康、身体、食、睡眠などに関する野人理論の原典記述が含まれます。

これらは「野人さんが何を述べているのか」を原典から追跡するための研究・整理資料であり、医療上または健康上の助言を目的とするものではありません。また、このリポジトリー自体が各記述の現代科学・医学上の妥当性を確認したことを意味しません。

## 著作権と引用

野人さんの原典の著作権は、それぞれの権利者に帰属します。

このリポジトリーでは原典全文の転載を目的とせず、必要最小限の引用と要約を用いながら原典へのリンクを示します。

詳細は[著作権・引用・利用について](RIGHTS.md)を参照してください。

このリポジトリーは公開活動「観生｜生命を考える」の一部です。

「観生｜生命を考える」は観生プロジェクトの対外的なブランド表現であり、野人理論そのものの名称ではありません。

理人理論（仮称）は野人理論とは別の理論として扱い、このリポジトリーにはその理論内容を混在させません。

## この活動の目的

野人理論を広めることより先に、野人さんが何を述べたのかを出典を追える形で正確に伝えることを優先します。

原典を転載・代替するのではなく、原典へ導くこと。

野人理論を完成させるのではなく、理解を助けること。

野人さんを代弁するのではなく、読者が自分で原典を読めるようにすること。

そのための入口として、このリポジトリーを整備します。
